# Arquitetura do Impacto Educacional

Projeto desenvolvido para o Datathon FIAP 2026

## Objetivo

Identificar precocemente estudantes com risco de defasagem educacional e avaliar a efetividade das intervenções realizadas.

## Funcionalidades

- Dashboard executivo
- Indicadores educacionais
- Avaliação de efetividade
- Modelo preditivo de risco educacional

## Tecnologias

- Python
- Streamlit
- Pandas
- Scikit-Learn
